Last.fm API key (needed for Dig)

How to get it
  1. Go to last.fm/api/account/create (make a free Last.fm account if you don't have one).
  2. App name: The Record Crate. Description: anything. Leave callback URL blank.
  3. Submit, then copy the API key (not the shared secret) and paste it here.

Discogs token (optional, better vinyl search)

How to get it
  1. Log in at discogs.com/settings/developers (free account).
  2. Tap Generate new token, copy it, paste it here.
  3. Without it, record search uses Apple's album catalog instead.

Unsplash access key (for playlist photos)

How to get it
  1. Join at unsplash.com/join, then go to unsplash.com/oauth/applications.
  2. Tap New Application, accept the terms, name it The Record Crate.
  3. Scroll to Keys and copy the Access Key.
